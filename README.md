# Retail Sales Analysis

## Project Overview

This project analyzes retail sales data to understand sales patterns, customer behavior, and product performance using Python and Machine Learning.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Google Colab

## Analysis Performed

* Data cleaning and preprocessing
* Product category sales analysis
* Monthly sales analysis
* Quantity analysis
* Top customer analysis
* Gender-wise sales analysis
* Correlation analysis
* Data visualization

## Business Insights

* Identified high-performing product categories.
* Analyzed monthly sales trends.
* Identified top customers contributing to revenue.
* Studied customer purchasing patterns.
* Correlation analysis helped identify relationships between sales-related factors.
* These insights help businesses improve marketing and inventory planning.

## Machine Learning

* Used **Linear Regression** for prediction.
* Used **Total Amount** as the target variable.
* Performed train-test split.
* Predicted Total Amount using the test data.
* Evaluated the model performance.

## Results

* Identified sales and customer patterns.
* Found high-performing product categories.
* Analyzed customer purchasing behavior.
* Built a Linear Regression model to predict Total Amount.

## Conclusion

This project helps understand retail sales, customer behavior, and product performance. The Linear Regression model helps predict Total Amount and supports data-driven business decisions.
