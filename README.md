# Retail Sales Analysis

## Project Overview
This project focuses on analyzing retail sales data to understand sales patterns, customer behavior, and product performance using Python.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed
- Data cleaning and preprocessing
- Sales analysis by product category
- Monthly sales trend analysis
- Product quantity analysis
- Top customer analysis
- Gender-wise sales analysis
- Correlation analysis
- Data visualization using charts

## Business Insights
- Identified high-performing product categories.
- Analyzed monthly sales trends.
- Found valuable customers contributing to revenue.
- Studied customer purchasing patterns.
- Identified relationships between numerical features.

##  Results

- Identified the best-performing product categories based on sales.
- Analyzed monthly sales trends to understand peak sales periods.
- Identified top customers contributing to overall revenue.
- Compared sales contribution across different genders.
- Studied the relationship between quantity sold and total sales amount using correlation and scatter plot analysis.

## Conclusion
This analysis helps businesses understand sales performance, customer behavior, and make data-driven decisions.
